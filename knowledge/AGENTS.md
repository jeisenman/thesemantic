# Knowledge source builds

Semantic owns this deterministic, offline source build boundary. The Rust CLI
invokes the compiled Go helper. No model, remote service, Python execution, source
checkout mutation, or protected Researcher implementation is used.

`lineagecheck` adapts the independently reviewed structural contract builder
from qtwo_bench. Only models, pinned blob verification, restricted literal schema
extraction, and validation were copied. This is owned source, not a dependency.
`build.go` reads a bounded trusted configuration and atomically publishes a typed
desktop export. `projection.go` maps declared datasets, jobs, columns, and edges.
No business meaning, SME approval, or undeclared source coverage is inferred.

Inputs require explicit absolute paths, full Git commits, reviewed source
digests, and a named scope/profile. Supported automatic extraction is limited to
literal primitive PySpark StructType schemas. Unsupported syntax fails closed.
Explicit reviewed field and dependency declarations remain human contracts.
Unknown findings prevent a build. Every output states the limited source scope.

Run `go test ./knowledge/... ./tools/...` and `go vet ./knowledge/... ./tools/...`.
Tests create only temporary synthetic Git repositories. No private manifests or
provider artifacts belong here. Keep every source/document file below 400 lines.
